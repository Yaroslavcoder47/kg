# Лабораторная работа №1: Конвертер цветовых моделей

## Цель работы

Целью данной лабораторной работы было изучение различных цветовых моделей (RGB, CMYK, HSV), их устройства, назначения, основных отличий и взаимодействий.

## Что было проделано в рамках подготовки к работе

В рамках подготовки к данной лабораторной работе было выполнено следующее:

- Прочитаны материалы лекций по тематике работы.
- Изучены три цветовые модели: RGB, CMYK, HSV.
- Реализованы функции для преобразования между цветовыми моделями.

## Написание программы

В качестве основного инструмента для реализации был выбран Python с использованием библиотеки `tkinter` для создания графического интерфейса. Программа позволяет:

- Выбирать цвет с помощью палитры.
- Вводить значения цветов в одной из моделей (RGB, CMYK, HSV) и автоматически пересчитывать их в другие модели.
- Отображать выбранный цвет в виде HEX-кода.

### Основные компоненты программы:

1. **Графический интерфейс**:
   - Используется библиотека `tkinter`.
   - Реализованы слайдеры и текстовые поля для ввода значений.
   - Отображение текущего цвета и его HEX-кода.

2. **Функционал преобразования**:
   - Реализованы функции для преобразования между моделями RGB, CMYK и HSV.
   - Используются модули `functions.py` для математических расчетов.

3. **Палитра цветов**:
   - Возможность выбора цвета через стандартный инструмент выбора цвета.

## Выводы

В ходе выполнения работы были изучены особенности цветовых моделей, их устройство и использование в графических системах. Также были усвоены принципы математического представления и преобразования между заданными моделями. Программная реализация позволила закрепить эти знания на практике, а также освежить навыки разработки графических интерфейсов на Python.

## Запуск программы

1. Убедитесь, что у вас установлен Python версии 3.7 или выше.
2. Установите необходимые зависимости (если они указаны в `requirements.txt`).
3. Запустите файл `gui.py`:

```bash
python gui.py
```
