# Лабораторная работа №2: Обработка изображений

## Цель работы

Целью данной лабораторной работы было изучение методов обработки изображений, включая улучшение контраста, эквализацию гистограмм и применение нелинейных фильтров.

## Что было проделано в рамках подготовки к работе

В рамках подготовки к данной лабораторной работе было выполнено следующее:

- Прочитаны материалы лекций по обработке изображений.
- Изучены методы улучшения контраста и эквализации гистограмм.
- Изучены принципы работы нелинейных фильтров (медианный, минимальный, максимальный).

## Написание программы

Программа реализована на языке Python с использованием библиотек OpenCV и Matplotlib. Она включает следующие функции:

### Основные компоненты программы:

1. **Улучшение контраста**:
   - Линейное растяжение контраста.
   - Эквализация гистограммы для серых и цветных изображений (в RGB и HSV).

2. **Применение нелинейных фильтров**:
   - Медианный фильтр.
   - Минимальный фильтр.
   - Максимальный фильтр.

3. **Отображение результатов**:
   - Исходное изображение и обработанное изображение.
   - Гистограммы интенсивностей для сравнения.

### Используемые библиотеки:

- `OpenCV` для обработки изображений.
- `Matplotlib` для построения графиков и отображения изображений.
- `NumPy` для работы с массивами данных.

## Выводы

В ходе выполнения работы были изучены и реализованы методы улучшения качества изображений, включая линейное растяжение контраста и эквализацию гистограмм. Также были изучены и применены нелинейные фильтры для обработки изображений с шумами. Программная реализация позволила закрепить теоретические знания на практике.


## Запуск программы

1. Убедитесь, что у вас установлен Python версии 3.7 или выше.
2. Установите необходимые зависимости из файла `requirements.txt`:

```bash
pip install -r requirements.txt
```

3. Запустите файл `main.py`:

```bash
python main.py
```
