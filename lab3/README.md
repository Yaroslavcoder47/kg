# Лабораторная работа №3: Растеризация графики

## Цель работы

Целью данной лабораторной работы было изучение алгоритмов растеризации графики, их реализации и применения для построения базовых графических примитивов, таких как линии и окружности.

## Что было проделано в рамках подготовки к работе

В рамках подготовки к данной лабораторной работе было выполнено следующее:

- Прочитаны материалы лекций по алгоритмам растеризации.
- Изучены основные алгоритмы построения линий и окружностей: пошаговый алгоритм, алгоритм ЦДА (DDA), алгоритм Брезенхема для линий и окружностей.

## Написание программы

Программа реализована на языке Python с использованием библиотеки `tkinter` для создания графического интерфейса. Она включает следующие функции:

### Основные компоненты программы:

1. **Алгоритмы построения графических примитивов**:
   - Пошаговый алгоритм.
   - Алгоритм ЦДА (DDA).
   - Алгоритм Брезенхема для линий.
   - Алгоритм Брезенхема для окружностей.

2. **Графический интерфейс**:
   - Возможность выбора алгоритма через интерфейс.
   - Ввод координат для построения линий и окружностей.
   - Масштабирование и очистка холста.

3. **Отображение результатов**:
   - Построение графических примитивов на холсте.
   - Отображение координатной сетки и осей.

### Используемые библиотеки:

- `tkinter` для создания графического интерфейса.

## Выводы

В ходе выполнения работы были изучены и реализованы основные алгоритмы растеризации графики. Разработка программы на языке Python позволила закрепить теоретические знания и получить практические навыки работы с графическими примитивами. Программная реализация продемонстрировала эффективность и особенности различных алгоритмов построения линий и окружностей.


## Запуск программы

1. Убедитесь, что у вас установлен Python версии 3.7 или выше.
2. Запустите файл `main.py`:

```bash
python main.py
```
